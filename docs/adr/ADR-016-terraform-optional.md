# ADR-016: Terraform pentru Azure, opțional, după MVP

- **Status:** Accepted
- **Data:** 2026-10-18

## Decizie

Terraform pentru Azure, opțional, după MVP

## Alternative respinse

Doar Docker Compose

## Motiv

Arată IaC; nu e necesar pentru funcționare locală

## Notă

Completat de ADR-017: Terraform devine obligatoriu pentru deploy-ul pe Azure.

# ADR-005: TimescaleDB pentru telemetrie, Postgres pentru restul

- **Status:** Accepted
- **Data:** 2026-10-18

## Decizie

TimescaleDB pentru telemetrie, Postgres pentru restul

## Alternative respinse

InfluxDB, ClickHouse

## Motiv

Un singur motor SQL, familiar pentru echipe; hypertables pentru serii de timp
